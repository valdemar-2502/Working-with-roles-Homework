# LightHouse Role

Роль для установки LightHouse и Nginx.

## Переменные

| Переменная | Описание | По умолчанию |
|------------|----------|-------------|
| lighthouse_vcs | URL репозитория | https://github.com/VKCOM/lighthouse.git |
| lighthouse_dir | Директория установки | /var/www/lighthouse |
